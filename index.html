Key Traceability Points

Link Description
IIR → Material Issue Incoming Inspection feeds Material Issue (Qty Issued / Accepted)
Material Issue → FI / FG RC No is the primary key across all production stages
Heat No / Batch No Captured in Incoming Inspection for full material pedigree
CoC Register Certificate of Conformance linked at dispatch stage
End-to-end journey of a Route Card (RC) from Material Issue to Dispatch.

Standard RC Flow

Stage Sheet Key Action
1. Material Issue MATERIAL_ISSUE Create RC No, issue quantity, record machine / operator
2. Production MATERIAL_ISSUE Update Qty Accepted / Rework / NCR / Rejected
3. Final Inspection FI_Tracker_New Enter RC → auto-populate → set FI Clearance Status
4. Finished Goods FG_Tracker_New Enter RC → update Dispatch Qty, DC No, Invoice
5. Quality Gate RC_CONTROL Final RELEASE or BLOCK decision
6. Dispatch COC_REGISTER + FG CoC generation and physical dispatch

Primary Key

RC No is the single primary key that links Material Issue → FI → FG → FAIR → NCR → CAPA → CoC → PO Tracker.
